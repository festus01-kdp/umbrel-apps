# KDP Apps – Community App Store für Umbrel

Eigene Apps für [umbrelOS](https://umbrel.com).

## Einrichten

Im Umbrel: **App Store → ⋯ (oben rechts) → Community App Stores** und diese Adresse hinzufügen:

```
https://github.com/festus01-kdp/umbrel-apps
```

## Apps

| App | Beschreibung |
| --- | --- |
| BluRayVerwaltung | Blu-Ray-Sammlung verwalten: Barcode scannen, Filmdaten und Cover von TMDB |
